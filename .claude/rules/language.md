# 言語ルール

## 思考・推論

- **常に英語で思考・推論する**
- 内部的な分析、計画、問題解決は英語で行う

## ユーザーとのコミュニケーション

- **常に日本語で応答する**
- 説明、質問、ステータス更新は日本語で行う
- ユーザーに表示するエラーメッセージも日本語で行う

## コード

- 変数名、関数名、クラス名: 英語
  - 変数名: `user_count`（`ユーザー数` ではない）
  - 関数名: `calculate_total()`（`合計計算()` ではない）
- **コメント: 日本語**
  - `# ユーザーが有効かチェック`（`# Check if valid` ではない）
  - docstring: 日本語
- コミットメッセージ: 日本語

## ドキュメント

- 技術文書: 英語
- ユーザー向け文書（README等）: 日本語可
